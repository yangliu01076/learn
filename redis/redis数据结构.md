# 1 SDS (Simple Dynamic String)
## 要解决的问题
* 字符串长度计算：C语言的 strlen() 函数时间复杂度为 O(n)，
而SDS的 len 属性时间复杂度为 O(1) ，而且在redis中计算长度是
高频操作，所以需要优化
* 内存预分配：C语言的字符串以 '\0' 结尾，每次字符串操作都需要重新分配内存， 
而SDS的 len 属性记录了字符串长度，所以不需要 '\0' 结尾，并且可以
当字符串长度小于1MB时，每次扩容都预分配多一倍
* 二进制安全：C语言的字符串以 '\0' 结尾，需要感知字符串中的 '\0' 字符，二进制安全
就是说序列化处理的时候不需要感知内容，如果存图片什么的二进制数据很可能会出现 '\0'
，就会损坏文件，所以redis的key和value都是二进制安全的

## 数据结构
len 记录字符串长度，free 记录剩余空间，buf （char[]） 记录字符串内容
