# 进程与线程
* 进程是资源分配的最小单位，线程是 CPU 调度的最小单位。
* 一个进程包含多个线程，线程共享进程的内存空间（堆、全局变量），但各自有独立的
  栈、程序计数器和寄存器。
* 进程切换需要切换页表、虚拟内存空间，开销大。线程切换只需切换栈和寄存器，开销小。

# 进程间通信（IPC）
* 管道（Pipe）：半双工，父子进程间通信。命名管道（FIFO）可用于无亲缘关系进程。
* 信号（Signal）：异步通知机制，如 SIGKILL、SIGTERM。
* 共享内存（Shared Memory）：多个进程映射同一块物理内存，速度最快，需配合同步机制。
* 消息队列（Message Queue）：内核中的消息链表，克服信号和管道的信息量限制。
* 信号量（Semaphore）：用于进程间同步，P 操作（等待）和 V 操作（释放）。
* Socket：跨机器通信，也可用于本机（Unix Domain Socket）。

# 进程调度算法
* FCFS（先来先服务）：非抢占，简单但平均等待时间长。
* SJF（短作业优先）：非抢占，平均等待时间最短，但长作业可能饥饿。
* 优先级调度：按优先级调度，可能导致低优先级饥饿（可用老化策略解决）。
* 时间片轮转（Round Robin）：每个进程分配时间片，时间片用完切到下一个。公平但切换开销大。
* 多级反馈队列：综合以上，多个队列不同优先级和时间片，进程可在队列间降级。

# 内存管理
## 虚拟内存
每个进程有独立的虚拟地址空间，通过页表映射到物理内存。  
好处：进程隔离、内存按需分配、可使用磁盘交换扩展可用内存。  
## 页表与 TLB
* 多级页表：减少页表占用的内存空间（如 x86 四级页表）。
* TLB（Translation Lookaside Buffer）：CPU 内部的页表缓存，加速虚拟地址到物理地址的翻译。
  TLB 命中率高时，地址翻译几乎无开销。
## 页面置换算法
* LRU（最近最久未使用）：淘汰最长时间未访问的页面，效果好但实现开销大。
* Clock（时钟算法）：LRU 的近似，用访问位循环扫描，被访问过的页跳过。
* LFU（最不经常使用）：淘汰访问次数最少的页面。

# 死锁
四个必要条件：互斥、占有并等待、不可剥夺、循环等待。  
处理策略：  
* 预防：破坏四个条件之一（如资源有序分配破坏循环等待）。
* 避免：银行家算法，分配前检查是否安全。
* 检测与恢复：允许死锁发生，检测到后杀死进程或回滚。

# I/O 模型
* 阻塞 I/O：调用方阻塞等待数据就绪和拷贝完成。
* 非阻塞 I/O：数据未就绪时立即返回 EAGAIN，调用方需轮询。
* I/O 多路复用（select / poll / epoll）：一个线程同时监听多个 fd，阻塞等待任一就绪。
  * select：1024 个 fd 上限，每次全量遍历，O(n)。
  * poll：无 fd 数量限制，仍全量遍历。
  * epoll：事件驱动，只返回就绪的 fd，O(1)，支持 Edge Triggered 和 Level Triggered。
* 信号驱动 I/O：内核数据就绪时发 SIGIO 信号，应用层异步处理。
* 异步 I/O（AIO）：内核完成数据拷贝后通知应用层，真正的异步。Linux 用 io_uring。
