# 冯诺依曼架构
五大部件：运算器、控制器、存储器、输入设备、输出设备。  
核心思想：程序和数据存储在同一内存中，CPU 按指令周期从内存取指、译码、执行。  
现代 CPU 将运算器和控制器集成在芯片中，合称 CPU。  

# CPU 结构
* ALU（算术逻辑单元）：执行算术和逻辑运算。
* CU（控制单元）：取指、译码、产生控制信号，驱动各部件协作。
* 寄存器：最快存储，CPU 内部。
  * PC（程序计数器）：下一条指令地址。
  * IR（指令寄存器）：当前正在执行的指令。
  * ACC（累加器）：存放操作数和运算结果。
  * PSW（程序状态字）：记录 CPU 状态（零标志、进位标志、溢出标志等）。

# 存储层次
按速度从快到慢、容量从小到大：  
* 寄存器：CPU 内部，纳秒级，几十个。
* Cache（L1 / L2 / L3）：SRAM，L1 纳秒级，L3 十纳秒级。L1/L2 级私有，L3 多核共享。
* 内存（RAM）：DRAM，百纳秒级，GB 级。
* 磁盘（SSD / HDD）：微秒到毫秒级，TB 级。
* 远程存储（网络）：毫秒级以上。  
越上层越快越贵越小，越下层越慢越便宜越大。层次设计的核心是利用局部性原理
（时间局部性 + 空间局部性），让 CPU 大部分时间命中上层。  

# Cache
* 映射方式：
  * 直接映射：每个内存块只能映射到固定的 Cache 行，硬件简单但冲突率高。
  * 全相联映射：内存块可映射到任意 Cache 行，冲突率低但查找开销大。
  * 组相联映射：折中，Cache 分组，每组内全相联。实际最常用。
* 写策略：
  * 写直达（Write-Through）：同时写 Cache 和内存，简单但慢。
  * 写回（Write-Back）：只写 Cache，被替换时才写回内存，快但需要脏位标记。

# 指令流水线
将指令执行分为多个阶段（经典五级）：取指 -> 译码 -> 执行 -> 访存 -> 写回。  
每个阶段并行处理不同指令，提高吞吐率。  
流水线冒险（Hazard）：  
* 结构冒险：多条指令同时需要同一硬件资源。
* 数据冒险：后续指令依赖前一条指令的结果（可用转发/旁路解决）。
* 控制冒险：分支指令导致下一条指令地址不确定（可用分支预测解决）。  

# 总线
* 数据总线：传输数据，宽度决定一次传输的数据量（如 64 位）。
* 地址总线：传输地址，宽度决定寻址空间（如 32 位地址总线可寻址 4GB）。
* 控制总线：传输控制信号（读/写、中断请求等）。

# I/O 方式
* 程序查询：CPU 轮询 I/O 状态，效率最低。
* 中断：I/O 设备就绪后发中断信号，CPU 响应处理。CPU 利用率高，但每次中断有开销。
* DMA（直接内存访问）：DMA 控制器直接在 I/O 设备和内存之间搬运数据，CPU 只在
  开始和结束时参与，适合大批量数据传输。
