# MyBatis 源码深度探索路线图

> 本地图旨在引导从“会用”到“精通”的进阶之路，按优先级和关联度排序。

## 第一阶段：核心链路
*我们已经通过 Debug 跑通了主流程，这是看懂其他模块的基础。*

| 模块       | 核心类/接口                              | 关键设计模式 | 学习重点                                       |
|:---------|:------------------------------------|:-------|:-------------------------------------------|
| **配置加载** | `XMLConfigBuilder`, `Configuration` | 建造者模式  |  XML 解析流程，MappedStatement 的生成               |
| **动态代理** | `MapperProxy`, `MapperProxyFactory` | 动态代理模式 | 接口是如何被实例化并拦截调用的                            |
| **执行路由** | `MapperMethod`, `SqlCommand`        | 策略模式   |  `selectOne` 与 `selectList` 的路由逻辑           |
| **执行器**  | `BaseExecutor`, `SimpleExecutor`    | 模板方法模式 |  JDBC 的真正执行者，一级缓存的存取                        |
| **缓存机制** | `CachingExecutor`, `BaseExecutor`   | 装饰器模式  |  一级缓存与二级缓存的交互，`EXECUTION_PLACEHOLDER` 防循环依赖 |

## 第二阶段：高级特性
*这部分是面试和实战中最常见的“深水区”，也是提升编码能力的关键。*

### 1. 插件机制
*PageHelper 等工具的核心原理，必须掌握。*

| 核心类                | 作用    | 关键点                                    | 探索任务                            |
|:-------------------|:------|:---------------------------------------|:--------------------------------|
| `Interceptor`      | 插件接口  | 定义 `intercept` 方法，`@Signature` 注解指定拦截点 | [ ] 尝试写一个打印 SQL 执行耗时的插件         |
| `Plugin`           | 插件代理类 | 使用 `Plugin.wrap` 生成目标代理对象              | [ ] Debug 查看 `target` 是如何被层层包裹的 |
| `InterceptorChain` | 拦截器链  | 管理所有插件，`pluginAll` 责任链调用               | [ ] 分析多个插件同时存在时的执行顺序（洋葱模型）      |

### 2. 动态 SQL
*XML 中 `<if>`, `<foreach>` 的底层实现，组合模式的教科书。*

| 核心类              | 作用       | 关键点                                   | 探索任务                                  |
|:-----------------|:---------|:--------------------------------------|:--------------------------------------|
| `SqlNode`        | SQL 节点接口 | 所有标签（`WhereSqlNode`, `IfSqlNode`）的父接口 | [ ] 查看 `MixedSqlNode` 如何管理子节点列表       |
| `DynamicContext` | 动态上下文    | 拼接 SQL 字符串，收集参数                       | [ ] Debug `apply` 方法，看 SQL 是如何一点点拼出来的 |
| `Ognl`           | 表达式引擎    | 解析 `<if test="user != null">` 中的表达式   | [ ] 了解 MyBatis 如何调用 OGNL 计算 Boolean 值 |

### 3. 类型处理器
*解决 Java 类型与 JDBC 类型的转换，实现加密/脱敏的关键。*

| 核心类                   | 作用     | 关键点                                   | 探索任务                                 |
|:----------------------|:-------|:--------------------------------------|:-------------------------------------|
| `TypeHandler`         | 类型转换接口 | `setParameter` (入参), `getResult` (出参) | [ ] 自定义一个 `CryptoTypeHandler` 实现入库加密 |
| `TypeHandlerRegistry` | 注册中心   | `JdbcType` 与 `TypeHandler` 的映射关系      | [ ] 查看 `register` 方法，看 Map 结构是如何初始化的 |

## 第三阶段：架构与扩展
*深入理解框架的底层设计，适合架构师方向。*

### 1. 二级缓存
*跨 Session 的缓存，分布式场景下的“双刃剑”。*

| 核心类                  | 作用   | 关键点                                     | 探索任务                                     |
|:---------------------|:-----|:----------------------------------------|:-----------------------------------------|
| `TransactionalCache` | 事务缓存 | 事务提交前暂存数据，提交后刷入二级缓存                     | [ ] Debug `commit()`，理解为什么脏数据不会在事务内被别人读到 |
| `Cache`              | 缓存接口 | 装饰器模式的各种实现（`LruCache`, `BlockingCache`） | [ ] 研究 `BlockingCache` 是如何防止缓存击穿的        |

### 2. 对象工厂与反射
*MyBatis 如何高效创建对象和处理属性。*

| 核心类             | 作用    | 关键点                            | 探索任务                                  |
|:----------------|:------|:-------------------------------|:--------------------------------------|
| `ObjectFactory` | 对象工厂  | `create` 方法实例化对象               | [ ] 了解它如何处理无参构造函数                     |
| `Reflector`     | 反射元数据 | 缓存类的 `getter/setter` 方法，避免重复反射 | [ ] 对比 JDK 原生反射，理解 `Reflector` 的性能优化点 |

### 3. 数据源与连接池
*MyBatis 如何管理数据库连接。*

| 核心类                  | 作用     | 关键点            | 探索任务                             |
|:---------------------|:-------|:---------------|:---------------------------------|
| `UnpooledDataSource` | 无池化数据源 | 每次获取都新建连接      | [ ] 阅读源码，理解 JDBC 连接的标准获取流程       |
| `PooledDataSource`   | 池化数据源  | 复用连接，活跃/空闲连接管理 | [ ] 研究 `popConnection`，如何从池中获取连接 |

## 📝 学习建议

1.  **不要死记代码：** 记住“谁调用了谁”的关系（调用链）比记住代码细节更重要。
2.  **带着问题 Debug：** 比如想搞懂插件，就打断点在 `Plugin.invoke`，看看到底进来了几次。
3.  **动手造轮子：** 不要只看！尝试照着源码写一个简化版的 `SqlSession` 或者 `Interceptor`。
